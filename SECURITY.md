# Security

Please don't report security problems in public issues. Use GitHub's private reporting instead:
on the repository's **Security** tab, choose **Report a vulnerability**.

Include what you found, how to reproduce it, and which version or commit you tested. You'll get a
reply within a week. Fixes go into the latest release; older pre-1.0 releases don't get backports.

Things that are in scope include anything that could leak a Roblox API key, a universe secret's
value or the contents of a state file, and anything that lets a config or an API response make
Baseplate act on resources it wasn't asked to touch.
